# chifir-tech

A teleshopping-style landing page for a tea strainer with a built-in readiness indicator.

Single static `index.html`, no build step. Fonts load from Google Fonts. The order form does not send anything, and the phone number is not real.

Deploy: push `index.html` to the `chifir-tech` repo and enable GitHub Pages (Settings → Pages → main branch, root). The site will be at `https://wildjoey.github.io/chifir-tech/`.

Parody site. Nothing is for sale.
